# Harbor

Every financial document, one clear picture. Built at the LPL Financial hackathon (October 2026) by Group 22, a team of 5. Fictional data only.

Clients upload financial documents; Harbor redacts private details before upload, then uses AWS (S3, Lambda, Textract, Amazon Bedrock with Nova Lite) to summarize them into a dashboard of net worth, assets, liabilities and goals.

Team: Abdelraouf Yassin (team lead: concept, features, pitch deck, pipeline contributions), Aditya Patel, Sarah Sayeed, Surya Sathanapalli, Shelton Bumhe.
